# 数愈科研 · 独立产品页面

## 设计决策

沿用已确认的设计基线，模式为 Redesign · Preserve。此次拆分规范与产品 HTML，不改变基础设计规范。面向桌面科研用户，界面安静、紧凑、以浏览与选择工作流为中心。

- 视觉变化 2/10；动效 1/10；信息密度 6/10；素材依赖 3/10；品牌一致性 10/10。
- 左侧产品导航固定 260px；中央顶部导航固定 56px；右侧面板展开时固定 400px；内容与固定区域保留 38px 安全边距。对话工作区使用 800px，能力频道、能力详情、科研空间、文件管理和缺省页使用 960px；宽屏只增加外围留白。
- 品牌蓝 #3478F6；主区域 #FFFFFF；侧栏 #F7F8FA；边框 #E2E5E9；正文 #000000，次级文字 #666666。
- 字体沿用 PingFang SC 等系统中文字体。操作文字 14px/22px，辅助文字 12px/18px。
- 卡片 8px；输入、标签 6px；大输入框 16px；行动按钮沿用胶囊形。
- 选中 Tab 为品牌蓝文字与 2px 下划线，二级标签选中为品牌蓝描边；卡片悬停仅改浅灰底，箭头与下载保持灰色。
- 间距按 4px 倍数，主区 32px 起始留白；搜索、筛选、卡片共用阅读轴。

## 已有素材

- Logo: `assets/shuyu-logo.png`，复制自 `../../visitor/assets/shuyu-logo.png`（项目根目录的 visitor）。
- UI icons: `assets/*.svg`，从项目 `src/components/icons.js` 现有图标导出；不重绘品牌标识。
- Markdown 图标：复用 `../app.js` 的字形和 `../style.css` 的实心折角结构，使用用户参考中的灰色 Markdown 样式。
- 参考：用户提供的全局骨架、筛选与频道截图；`../skeleton.html`、`../index.html` 为冻结规范。

## 文件边界

- `../workflows.html`、`../workflow-detail.html`、`../workflow-preview.html` 为文字规范与打开入口。
- 本目录中的同名三个 HTML 为独立的完整产品页面，不嵌入设计规范外框。
- 所有产品样式和交互仅位于本目录，冻结的 `../index.html`、`../style.css`、`../app.js` 不修改。
- 数据为已有工作流名称与示例材料。数量依据实际展示的数据计算；样例不声明真实临床结果。
