# 能力页面：规范与产品演示分离

三个独立页面可直接用浏览器打开，不依赖构建或在线资源。

| 文字规范（上一级目录） | 独立产品页面 | 用途 |
| --- | --- | --- |
| `../workflows.html` | `workflows.html` | 浏览、搜索、筛选和收藏能力 |
| `../workflow-detail.html` | `workflow-detail.html` | 了解能力、查看案例、保存任务配置 |
| `../workflow-preview.html` | `workflow-preview.html` | 回放真实任务对话、执行过程与交付结果 |

规范页保留顶部导航、左侧目录和文字描述；右上大号蓝色链接在新窗口打开对应产品页面。产品页面不包含规范外框，也不在规范中嵌套展示。

## 维护边界

- 产品结构：上述三个 HTML。
- 产品公共样式：`product.css`。
- 示例工作流数据：`product-data.js`（6 个已有工作流名称）。
- 产品交互：`product.js`。
- 品牌来源与冻结设计基线：`brand-spec.md`。
- 文字规范专用样式：`../page-spec.css`。

原有 `../index.html`、`../style.css`、`../app.js`、`../skeleton.html`、`../free-chat.html`、`../task-chat.html` 均未修改。后续调整产品效果时，只修改本目录，不影响已确认的基础设计规范。

## 本地演示范围

搜索、两级分类、数量、收藏、章节定位、案例对话回放、文件查看与任务配置保存均可操作。产品侧栏不设置页面跳转超链接，避免演示时误离开当前页面；配置保存在本地，尚未接入实际任务执行。

## 校验

使用独立本地无头环境验证，未读取或操作用户的浏览器：

- 1440px 下左栏 260px、顶栏 56px、安全边距 38px；能力频道与能力详情使用 960px 内容轨道，能力预览以真实任务对话形式使用 800px 内容轨道，主区域纯白。
- 三个规范入口和三页产品路径可用。
- 搜索、分类/标签、收藏、空结果、返回状态正常。
- 不同能力的详情、案例及下载内容匹配。
- 配置可保存、重开；保存失败保留输入。
- 1100px 与 390px 下无页面水平溢出，无脚本异常。

结果记录见 `qa/checks.json`，本地渲染图保存在 `qa/`。
