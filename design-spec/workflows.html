能力频道页

用于发现和选择科研工作流。主体只组织频道描述、搜索、筛选与收藏四类内容，统一使用 960px 最大内容轨道。

01 / DESCRIPTION

频道描述

信息任务
用一段完整但克制的介绍说明能力面向谁、提供什么专业工作流、如何保证医学方法与证据质量。描述先建立专业可信度，再引导用户输入研究方向或分析瓶颈。
标题组合
机器人图标与主标题紧密排列并左对齐；主标题只占一行。描述位于标题下方并与正文阅读轴对齐，不使用独立大卡片包裹。
表达边界
优先使用医生和研究者能直接理解的语言，说明“能解决什么”和“依据如何复核”。验证数量、专家参与等信息只有在有真实依据时才展示。

02 / SEARCH

搜索模块

统一输入
搜索与智能助手共用一个输入框，用户只需描述研究方向、材料或当前瓶颈。输入区是频道的主操作，不再拆成两个相互竞争的表单。
两种动作
输入框提供“闪电搜索”和“AI 推荐”两个大圆角按钮，并分别配搜索语义图标与 AI 语义图标。闪电搜索直接匹配名称、用途和标签；AI 推荐根据自然语言理解任务并推荐工作流。
布局关系
搜索输入区约占两张能力卡片的宽度，右侧展示三行自适应案例胶囊。输入区与案例区等高，输入框采用 1px 蓝色边框和轻投影；案例胶囊使用灰色背景、不加投影，文字长度可不同但不得越过安全区。

03 / FILTER

筛选模块

一级分类
一级分类使用横向文字导航，每项配置独立图标与结果数量；默认入口命名为“推荐”。选中项使用品牌蓝文字和 2px 下划线，未选中项保持中性灰。
二级筛选
二级筛选紧接一级分类下方并直接左对齐，不显示“二级标签”等解释性标题。筛选项使用矩形标签，选中项为蓝色边框，未选中项为浅灰背景；数量随当前一级分类更新。
结果状态
搜索、一级分类和二级筛选共同决定结果。结果直接以三列丰富能力卡片呈现，不增加“共多少个工作流”等重复说明；无结果时提供清除条件或返回推荐的入口。

04 / FAVORITE

收藏模块

频道入口
收藏放在一级分类行最右侧，与分类导航保持同一基线。心形图标、文字和数量统一使用红色，入口不与“推荐”混为同一分类。
卡片操作
每张能力卡片右下角保留独立收藏按钮。点击只更新收藏状态，不触发卡片跳转；收藏数量和频道收藏结果同步变化。
收藏结果
点击频道收藏入口后只展示已收藏能力，并继续允许搜索和二级筛选。没有收藏内容时使用 960px 缺省页规则，引导用户返回推荐能力。
